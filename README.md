# Conecta Biblioteca

## Propósito
Fortalecer las competencias digitales mediante puntos itinerantes de alfabetización digital en espacios comunitarios.

## Alcance
Piloto de cuatro meses. Incluye preparación, articulación, convocatoria, ocho jornadas, seguimiento y cierre.

## Equipo y responsabilidades
- Fabián Gamba: coordinación y decisiones
- Víctor Hernández: operación territorial.
- Katherine Vásquez: formación y contenidos.
- Andrea Figueroa: seguimiento y documentación.
  
## Organización de documentos
- `01_formulacion/`: ficha del proyecto y documentos de alcance.
- `02_evidencias/`: productos y evidencias autorizadas que ya existan.
- `03_seguimiento/`: acuerdos, decisiones y reportes de avance.

## Cómo se gestiona
Cada actividad se registra como Issue y se visualiza con GitHub Projects. El cierre requiere evidencia y verificación, no solamente cambio de estado.

## Protección de datos
No se publican datos personales identificables ni información reservada.
